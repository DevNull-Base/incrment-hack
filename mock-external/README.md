# Имитатор внешних систем

Занимает место двух систем ИТ Школы, доступа к которым нет: **LMS**, где
проходит обучение, и **сайта** на CMS Laravel, откуда приходят обращения.
Обе перечислены в разделе 5 технического задания как источники данных; на
сессии вопросов и ответов заказчик подтвердил, что контракт передан не будет —
системы в переработке.

Вузовские LMS (Moodle и подобные) к обмену отношения не имеют: в задании их
нет, а контур стенда допускает наружу ровно два адреса — «жёсткий точка-точка
с конкретными портами», как это было сформулировано на сессии.

## Зачем отдельная служба

Внутри CRM есть режим заглушек (`INTEGRATION_MODE=stub`): он доказывает, что
код обмена работает, но обмена по сети при этом не происходит. Проверяться же
будет именно двусторонность. Отдельная служба ведёт себя как настоящая внешняя
система — отвечает по HTTP, хранит своё состояние и сама вызывает CRM.

Когда заказчик передаст контракт, имитатор выключается, а в настройках
прописываются настоящие адреса. Код приложения при этом не меняется.

## Ручки

Две системы — два порта: `4010` (LMS) и `4011` (сайт). Набор ручек одинаковый
и повторяет контракт, объявленный CRM.

| Метод | Назначение |
|---|---|
| `GET /api/crm/events?since=` | События для CRM, постранично по курсору |
| `POST /api/crm/engagements` | Приём состояния заявки от CRM (контракт `engagement.v1`) |
| `GET /api/crm/received` | Что CRM прислала — для показа и разбора |
| `POST /api/crm/emit` | Создать обращение и сразу отправить его в CRM подписанным вызовом |
| `GET /` | Состояние системы и перечень ручек |

Последняя ручка нужна для демонстрации: нажатие — и в CRM за секунду
появляется новая заявка, пришедшая «снаружи», без ожидания опроса.

## Запуск

Вместе со стеком:

```bash
docker compose --profile app up -d mock-external
```

Отдельно:

```bash
node mock-external/server.mjs
```

| Переменная | Назначение |
|---|---|
| `MOCK_LMS_PORT`, `MOCK_SITE_PORT` | Порты систем, по умолчанию 4010 и 4011 |
| `CRM_BASE_URL` | Адрес CRM для обратных вызовов |
| `INTEGRATION_WEBHOOK_SECRET` | Общий секрет подписи; тот же, что у CRM |

Со стороны CRM нужны `INTEGRATION_MODE=live` и адреса источников, указывающие
на имитатор. Проверка обмена целиком:

```bash
node test/manual/integration-live-check.mjs
```

## Ограничения

Состояние хранится в памяти: перезапуск возвращает исходный набор событий.
Это сделано намеренно — имитатор нужен для показа обмена, а не для хранения
данных, и повторная демонстрация начинается с чистого листа.
