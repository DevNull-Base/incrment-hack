# Idea.txt — Полная аналитика проекта CRM ИТ-Школы РТК

## Источник
Хакатон Leaders of Digital Transformation (LCT)
Кейс: Система контроля взаимодействия с учебными заведениями для приобретения навыков работы с востребованными на рынке цифровыми инструментами

---

## Заказчик
- **Организация:** ИТ-Школа РТК, ООО «Ростелеком Информационные Технологии»
- **Кейсодержатель:** Александр Крылов, технический директор
- **Эксперты:** Крылов А.А., Кушнарев И.А. (руководители проектов), Исаева Е.В. (главный системный аналитик)
- **Роль ИТ-Школы:** Оператор федеральных образовательных проектов в сфере IT

## Миссия
1. **Просветительская** — растить новое поколение IT-специалистов, востребованных на рынке
2. **Оптимизационная** — сократить трудозатраты сотрудников ИТ-Школы РТК за счёт автоматизации

## Нормативная база
- Поручения Правительства РФ по развитию кадрового потенциала в сфере IT
- Федеральные проекты по подготовке IT-специалистов
- **152-ФЗ «О персональных данных»** — обязательно
- **Приказ ФСТЭК № 117** — обязательно

## Ранжирование программ (3 метрики)
1. Заявки на обучение
2. Количество обучающихся
3. Количество параллельных потоков

## Workflow взаимодействия с вузом (14 шагов)
1. Поиск контактов ответственного в вузе
2. Коммуникация — уточнение актуальности IT-программ
3. Организация встречи с представителями вуза
4. Обмен пакетом документов для подписания
5. (Опционально) Корректировка документов перед подписанием
6. Подписание документов
7. Передача обучающих материалов, лицензии IT-продукта и документации в вуз
8. Сопровождение внедрения IT-продуктов в вузе
9. Обучение преподавателей
10. Актуализация учебной программы с учётом обучения преподавателя и добавления IT-продукта
11. Ведение занятий
12. Актуализация документации по продукту и обучающим материалам
13. Повышение квалификации преподавателей
14. Контроль за исполнением каждого этапа (сквозной)

## Акторы

### Внутренние (ИТ-Школа РТК)
- Менеджер по взаимодействию с вузами
- Руководитель проекта
- Методист / Куратор программы
- Администратор системы
- Аналитик

### Внешние (со стороны вуза)
- Контактное лицо вуза
- Преподаватель
- Студент (косвенно через LMS)

### Системные
- LMS (внешняя система управления обучением)
- Сайт ИТ-Школы (источник заявок)
- Массив статистических данных

## Архитектурные блоки

### A: Управление вузами и контактами
- Единый реестр вузов и контактных лиц
- Один вуз → множество программ
- История контактов

### B: Управление взаимодействиями (ядро)
- Каждое взаимодействие = Вуз + Программа + IT-продукт
- Kanban-доска по 14 этапам
- Визуализация жизненного цикла

### C: Управление документами
- Шаги 4-6 workflow
- Версионность
- Жизненный цикл: черновик → согласование → подпись

### D: Управление передачей материалов и лицензий
- Шаги 7, 12 workflow
- Версионность материалов
- Контроль сроков лицензий

### E: Управление обучением преподавателей
- Шаги 9, 10, 13 workflow
- Интеграция с LMS

### F: Хранилище контента
- Документы, материалы, лицензии, протоколы
- Версионность, шифрование

### G: Уведомления и коммуникация
- Email, in-app уведомления
- Напоминания, дедлайны

### H: Аналитика, отчётность и ранжирование
- Дашборды
- 3 метрики ранжирования
- Отчёты для федеральных проектов

### I: Интеграции (API Gateway)
- LMS (двусторонняя)
- Сайт ИТ-Школы
- Массив статистических данных

### J: Безопасность и администрирование
- RBAC
- Аудит лог
- 152-ФЗ + ФСТЭК № 117

## Ключевые фичи

### UX-упрощения
- Drag & Drop Kanban
- One-Click Document Pack
- Bulk Operations
- Quick Status View
- Шаблоны и предзаполнение

### Интеграции
- LMS (двусторонняя): CRM → LMS (программы, материалы, лицензии) | LMS → CRM (статус, прогресс)
- Сайт: Сайт → CRM (заявки) | CRM → Сайт (список программ)
- Email (SMTP)
- Telegram Bot (опционально)
- Внешние данные: HH.ru, реестр вузов

### Федеральный масштаб
- Региональная аналитика (карта России)
- Отчётность для госзаказчика
- Multi-Program Tracking (один вуз → N программ)

## Нефункциональные требования
- RBAC (3 роли: USER, MANAGER, ADMIN)
- Аудит всех действий
- Шифрование ПД
- Локализация данных в РФ
- API Gateway
- Масштабируемость
- Версионность документов и материалов

- **Иконки:** @mynaui/icons-react
- **Моковые данные:** встроенные моки для разработки без бекенда
